FUNNY

Make a shortcut! It turns up in the share sheet of Safari and Chrome and of the Instagram, TikTok and X apps, and it files the candidate outright - no page opens.

  1. Open Shortcuts, press +, and name it FUNNY.
  2. In its settings turn on Show in Share Sheet. Under Accepted Types leave only URLs and Safari web pages on, or it offers itself for photos and text as well.
  3. Add Ask for Input, question: Your two cents? - you have the joke in your head now, and there is no way to write it later.
  4. Add Get Contents of URL with the address below. Set Method to POST. Add two headers: apikey with the key below, and Content-Type set to application/json.
  5. Set Request Body to JSON with two fields: p_post_url = Shortcut Input, and p_why = Provided Input.
  6. Add Show Notification showing the Contents of URL, so you get back added or duplicate and know it landed.

The key is the publishable one, already committed in this site and readable by anyone who views source. It can file a candidate and do nothing else: not read the queue, not rule on one, not delete.

The first time you use it, scroll to the end of the share sheet and press Edit Actions to pin FUNNY near the top. After that it is one tap.

Chrome on Android has no share-sheet entry for a page like this one, so there are two ways in and neither is as neat as the iPhone's.

  1. Paste it. Copy the link, open the Socializer, and paste it into ADD POST CANDIDATE. Nothing to install, works from every app.
  2. Or run the bookmarklet. Save the line from the BOOKMARKLET tab as a bookmark. Then, on the post, type that bookmark's name into the address bar and pick it out of the list. It runs exactly as it does on a desktop, and fills in everything.

A proper share-sheet entry is possible here - Chrome supports one for sites installed to the home screen - but the Socializer has to be set up as an installable app first. Worth doing if Android is where you actually browse.
